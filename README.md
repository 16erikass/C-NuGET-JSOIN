
C# NuGET, JSOIN

Užduotis atlikta sėkmingai.

## Atlikti darbai:

Create manual JSOIN file.

Add new entries to a JSON object .

Deserialize all entries (need LOOP)  the JSON data into C# objects and output the data into the console.

Use inheritance to extend the User class and create specialized user_types (ex.: admin, user, etc).

Create new JSOIN file with user_types data and deserialize the file . Output the data to the console.( failai yra bin/debug/net10.0 vardu users.json ir usertypes.json)
